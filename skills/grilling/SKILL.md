# 理清需求

从当前对话和已有材料开始，用中文讨论。只要求讨论时，交付讨论结论，不写项目文件或开始实施。

1. 简短复述要解决的问题、已知约束和本次范围；复用用户已经确认的内容。
2. 从具体用法追问：谁从哪里进入，输入什么，进行什么操作，得到什么结果。查看相关代码或资料，事实调查由 Agent 完成。
3. 默认一次聚焦一个会改变方案的关键问题，给出推荐答案和主要代价；用户要求集中提问时合并互不依赖的问题。
4. 随回答更新理解，区分要求、建议和未验证假设。低风险可逆细节给出合理默认值，重要未知先调查或保留。
5. 当目标、主要流程、范围和完成标准足以支持下一步时收束，说明已定事项和关键未知。

后续动作取决于用户当前意图和已有授权。已有材料足够时直接使用，不要求先生成 Spec、领域模型或任务。
