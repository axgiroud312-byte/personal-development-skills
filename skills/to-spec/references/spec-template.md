# Spec 编写模板

按当前能力或连贯目标使用。保留对实施有用的内容，小项目可以合并段落；已有项目模板优先映射，不要求照搬标题。删除无关占位项，不用猜测填空。多份 Spec 共享的约定引用现有来源。

完成标准是结果约定，不是要求立即编写测试。开发中优先实现与调整需求；必要验证、测试和构建集中到本次授权开发目标收尾，不因拆成多份 Spec 而重复安排。
