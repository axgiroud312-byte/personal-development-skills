# 协调多个任务并完成交付

执行方式读取同版本的 [implement](../implement/SKILL.md)：自主执行、集中开发、少测试，最后统一收尾。

承接 Spec、Issue 和已有设计中的目标与决定，结合实际代码判断已完成和剩余工作。调查围绕实施需要展开，新的事实或反馈出现时继续理解和修正判断；需要用户决定的取舍说明具体影响，其他工作继续。

## 按真实依赖推进

根据任务关系和当前进度安排实施、分工与整合。适合独立推进的工作可以分工，共享代码和接口明确负责人；受阻任务说明原因，其余可独立的工作持续推进。

交给执行者相关目标、要求、依据、工作位置和需要回交的成果，组织形式按任务需要决定。核对实际改动、已有检查和剩余事项后整合，实质变化同步相关执行者与 Issue。

尚不清楚且会影响结果的部分，选择合适的调查或具体表达来支持判断，沿用已有原型和资料。

## 统一收尾

本次授权范围内的成果整合后，按 implement 完成必要检查和交付。

将实际结果写回对应 Issue，说明成果位置、使用方式、待验证项和剩余事项。提交、推送和 PR 按已有授权处理，由整体负责人统一收尾。
