# 连续完成整套开发

主 Agent 负责多个任务的依赖、整合和整体交付。直接使用已有需求、Spec 或 Issue，只补执行所需的信息，不要求先跑完整套技能。

开始拆分或实施前，核对已有领域定义能否支持本次核心场景，足够时直接复用；不足或冲突时主动使用可用的 `domain-modeling` 或等价梳理补齐，再调整依赖这些定义的 Spec 与任务。涉及新增模块整体设计时，领域检查先于模块设计；小修不为流程补建文档。

涉及 UI 时，拆具体任务前读取已有设计目录总览、共享 Token、设计板、组件与原型，足够就复用；不足时衔接可用的 `design-ui` 或等价设计，与 Spec 配合补齐缺口。将真实设计入口、Token 唯一源、组件及 registry、原型源码和交互约定交给执行者，延续已有实现并按需安装。设计变化同步 Token、组件、设计板、原型和相关约定，不重复建设一套脱节的设计系统或组件。

前端未定选型参考可用 `design-ui` 主文件开头的技术栈与组件约定；已有项目方案优先。主 Agent 在前端实施前核对并补齐 shadcn 初始化与 registry 配置，保留已有定制；将实际配置与采用项交给执行者，具体依赖按本次需要选择。

## 建立任务与工作位置

1. 明确总目标、可观察的整体完成标准、已有进度和交付目标分支。已有 Issue 直接复用；Issue 驱动项目按当前方案补足可执行任务，每项写清目标、范围、局部设计、具体验收、领域与设计依据及阻塞关系，可结合 `to-tickets` 或自行整理。
2. 区分总目标与可独立执行的子任务。父子关系用于汇总，真实阻塞关系决定执行顺序；检查循环依赖和共享修改边界。
3. 保护原工作区。需要共同集成时选择集成分支；独立任务确有并行收益且环境支持时使用隔离工作树并委派，否则顺序完成。公共设计和共享源码明确维护者。

## 持续开发

4. 领取前置条件已满足的任务，给执行者 Issue、相关领域与界面设计依据、必要上下文、实际工作位置和验收目标，按 `implement` 的方法或等价步骤实施。具体代码写法由执行者在已有约束内判断。测试、审查分别按项目设置和改动风险选择；必要检查通过后，无新改动、失败或未解决问题就不重复扩大验证，不为流程生成构建产物。
5. 核对返回的代码、验证证据和未完成项，再整合到约定位置。依赖公共改动的任务取得对应代码后继续，不能只靠“已完成”的消息解除阻塞。
6. 更新 Issue 的局部设计、验收证据、当前结果、阻碍及分支/PR 关联。业务定义或规则变化时先维护公共领域记录，再同步受影响的 Spec、任务设计、验收与实现；整体技术设计或跨模块技术约定变化更新 Spec 与相关任务；呈现与交互变化更新设计规范及对应源码，再同步受影响任务。实际 Token 值只在共享源码维护，由样板与业务组件共用。共同决定只维护一份正文，其他位置引用，避免各执行者自行解释业务或设计。会改变目标或整体方案且无法调查解决的用户选择，给出推荐与影响后澄清。关键变更保留简短说明，不另建逐操作日志。
7. 继续所有已可执行任务，不在每项结束后询问是否继续。真实阻碍只暂停受影响部分；重复失败却没有新证据时明确报告阻碍，不无休止重试同一步。

## 整体 PR 与收尾

8. 按授权提交、推送集成结果并创建或更新整体 PR，列出覆盖的总目标、子 Issue、关键改动、逐项验证结果和未完成内容。可在有首批可提交结果时先建 Draft PR，后续持续更新；不要求每个子任务额外创建 PR。
9. 核对跨任务的接口、数据和真实使用流程，按整体完成标准与各任务验收检查可观察结果；UI 通过项目实际浏览器或桌面入口操作，核对关键流程、交互状态及视觉参考中的布局几何。保存可试用结果与必要说明，不以样板、提交、PR 或构建数量代替功能验收。只请求 PR 时保持待评审或待合并，不自动合并或关闭相关子 Issue 及总目标；按项目约定区分开发、验证和用户验收。
10. 确认各临时工作树的改动已整合、推送，并被实际建立的 PR 覆盖；把需要保留的交付物保存到待清理目录以外，确认保存成功且可访问。核对路径与归属、停止本任务占用进程，再清理本次无关构建产物及临时工作树，保留主工作区、他人修改和 PR 远端分支。
11. 核对清理后的实际残留。尚未交付的内容或失败任务的必要恢复材料保留并说明，不能为了收尾丢弃工作。只授权本地交付时保留承载未推送代码的工作树。

最终提供 Issue 与 PR 对应关系、整体试用入口、已验证结果、剩余阻碍，以及实际清理和保留内容。

用户要求“做完后解释”时，在完成整体交付后使用可用的 `explain-work` 讲清整体结果、主要变化及原因、关键流程和验证范围。该技能不可用时依据实际证据自行说明，不阻塞交付；讲解不能替代尚未完成的实施，也不在每个子任务后打断持续开发。
