# 设计表达参考

用于网页、Web 应用、后台、桌面 GUI、移动端等前端的效果预览。以下是制作时的设计原则，不是验收或质量检测流程，不要求评分、截图审查或自评循环；做好 HTML 和对应 Token 就交付，后续按用户反馈修改。

用户明确指定的组件、参考、字体、配色与动效优先，通用原则不能用于擅自替换。HTML 应首先呈现接近成品的完整页面；布局和业务行为可以简化，但导航比例、文字层级、背景关系和组件搭配要能表达最终观感，不让用户自己把零散组件拼成产品。

## 什么是好的设计

### 设计要符合这个项目

从功能、内容、品牌、独特限制或用户工作方式寻找依据，明确用户需要理解、相信或完成什么。布局表现内容的主次、因果与先后，避免无论什么项目都套“大标题、三张卡片、评价、价格表”。

有指定参考时，落实用户希望借鉴的部分，而不是另选一套 Agent 喜欢的风格。没有指定的部分再从产品特点寻找表达；工具界面可以通过真实任务与数据体现特点，不强加艺术表达或为新奇破坏熟悉的使用方式。

### 重要内容要先被看到

用大小、位置、疏密和明暗安排阅读顺序，让主任务先被看到，辅助信息仍清楚。避免每块都抢眼、字号都接近，或所有信息同样重要。

留白用于分组、突出重点或调整节奏。删掉装饰留下的洞、过大段落间隔和窄小文字旁的空地，不能只用“极简”解释；按内容补信息、放大重点或收紧布局。紧凑要分得清，宽松也要完整。

### 整个界面要像同一套设计

字体、色彩、间距、对齐、图片和组件相互配合，特点延续到正文、业务区与其他页面。保留表格、列表和同类操作中有助比较与理解的重复，不为求新破坏一致性。

颜色有明确用途，字体适合内容并清楚可读。渐变、阴影、细线、等宽字和圆角按指定方案与用途判断，不统一禁止；避免无理由反复堆叠。指定组件的变体、主题和定制应落在实际页面上，不只写一个库名。

### 页面要有可信的内容和密度

使用接近实际长度的中文、英文、数字与代表性样例，让导航、卡片、表格和正文具有可信的密度。内容简化不等于只摆空框或用极短占位词制造虚假的宽松感；样例不冒充真实业务数据。

图片应展示对象、环境或产品特点，重要细节可以放大。避免无关图库、过小截图、灰条假仪表盘或泛泛图标代替核心内容；素材不能冒充客户真实产品、人员或场所。

丰富感可来自充分内容、大小对比、图片、大面积色彩、排版或清楚组织的数据。简洁需要内容与细节，复杂需要秩序；不是必须增加装饰或功能。

### 状态和动效能在页面中被看到

动效用于表达变化、位置关系与反馈，体现指定的触发、时长、节奏和缓动，并能再次播放。加载、空数据、错误、成功等可用样例或开关展示，不必实现真实接口或完整业务。

页面切换、分页、弹窗开合只需足以看效果，保持样例清楚且操作轻量。需求包含窄屏时再安排对应布局，不对所有项目强制增加设备适配；动效保留减少动态效果的处理。

## 什么是不好的设计

不为填满空间或显得精致添加无作用的效果，也不用“高级感”“科技感”代替设计依据。下列是常见反例，不是覆盖用户明确要求的禁令。

| 问题 | 具体表现 |
| --- | --- |
| 无意义的渐变 | 背景、标题、按钮到处加渐变、发光或彩色光斑，与参考、品牌、内容和阅读顺序无关。 |
| 多余的小标签 | 反复加英文小标题、胶囊徽章、NEW、PREMIUM，既不帮助分类和导航，也不说明差异。 |
| 多余的介绍和小字 | 每个页面、卡片、控件都配介绍、口号或说明，删掉也不影响理解，却靠小字、变灰或拉大字距塞进去。 |
| 随意的小装饰 | 圆点、星形、十字线、角标、漂浮图形或无关图标没有表达作用，反而分散注意力。 |
| 装饰性或编造的数字 | 给无先后顺序的内容加编号，或把样例人数、销量、评分包装成真实业绩。 |
| 无依据的状态表达 | 没有对应需求却添加“系统正常”“实时同步”“AI 在线”等，或将演示中的成功冒充真实服务已接通。 |
| 预览与指定依据脱节 | 指定了组件、字体和参考，却用手写近似控件、回退字体和默认模板代替，且不说明差异。 |
| 只有组件，没有产品页面 | 色卡与按钮陈列齐全，但用户仍看不出导航、内容区和列表组合后的整体样子。 |

界面文字服务于识别、操作和理解，删掉后不影响这些目的的默认删去。例如标题已有“项目”，通常不必再写“在这里查看和管理你的所有项目”；不用小字或低对比度掩盖多余文字。

保留清楚可读的字段标签、输入要求、分类、步骤、金额与进度、状态和错误提示。模拟数据与临时替代在 HTML 附属说明区说清，避免每个组件都塞一段解释。

组件、开源库、字体及参考来源放在 HTML 的折叠说明区，与产品页面分开；直接使用、视觉模拟、联网资源与暂缺项如实区分，不另建来源报告。字体的真实加载或回退状态可以在该区域显示，不把仅声明字体名当作加载成功。

这些原则服务于制作效果，不要求交付前另开检查、验收或优化流程。Token 记录本版实际采用的样式，随预览修改更新，不代表已经定稿或通过生产验收。
