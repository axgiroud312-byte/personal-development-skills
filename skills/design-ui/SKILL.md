# 设计结构草图与完整前端原型

让用户在正式开发前看懂整套产品怎么组织、如何操作和最终观感。先组织信息架构，再落地视觉、组件、状态与动效，集中呈现在完整页面中。原型简化业务实现，保留影响设计判断的细节；HTML 是预览载体，不改变最终技术栈。

以代码和实际行为核实现状，已确认的新需求决定本次目标；文档冲突时沿用现有惯例并说明差异。只要求讨论或局部修改时完成该范围。

## 读取设计依据

读取需求、目标设备与尺寸、指定参考，以及已有设计记录、主题变量、组件配置和源码。打开原图、页面或文件，按用户意图借鉴布局、比例、排版、配色或动效；不能只抄背景色或混搭无关参考。

用户指定的组件变体、主题、字体、字重、配色、背景与动效优先。未指定细节合理补齐；资源不可访问、缺失或冲突时如实说明，只澄清真正阻止制作的选择。

## 组织全部页面与交互

汇总本次范围内全部页面、二三级子页、内容归属及父子关系；同模板记录可共用样例。按用户任务组织页面，Spec/Issue 的拆分不直接等于页面划分，完整产品原型不能只做首页。

落实全局与局部布局：导航位置、各级菜单、页内标签、分栏和滚动区，显示当前位置；不固定套用左侧栏。为每个入口选择独立页、页内切换、弹窗、抽屉或内联展开，明确进入、返回与关闭关系，完整原型中落实为可操作交互，不能用通用提示代替目标画面。

在目标窗口呈现可信的一屏信息量：导航宽度、内容比例、列表行数和行高、表格列宽、卡片数量、真实长度文字与换行。样例足以表现密度即可，按需求安排分页和设备适配，不扩大范围。

## 按需先做结构草图

用户要求先看布局或结构需要比较时，先出一次性 HTML 草图或 ASCII 线框；结构明确时可直接进入完整制作。遵循指定形式，未指定时用 HTML 判断实际尺寸、比例和一屏密度，用 ASCII 快速讨论页面组织。

草图标出目标窗口、导航与内容尺寸、分栏、滚动区，以及上述页面层级和打开关系，用代表性内容体现密度。默认一套；有实质不同的组织方式时再给少量备选。

只要求草图时按范围交付，ASCII 可直接在对话展示，不追加完整原型或 Token 文档；已授权完整设计则继续，不默认停等批准。HTML 草图可直接完善成最终原型，ASCII 由最终原型接替，不长期维护两套描述，也不把草图记成视觉与组件设计完成。

## 先复用或定义实际 Token

进入完整原型、编写组件前，读取 [设计系统与组件规则](references/design-system.md) 和 [好坏设计参考](references/design-quality.md)。前者统一样式与制作规则，后者辅助判断视觉取舍；两者都不追加验收流程。

先复用已有主题和共享组件，只补本次需要的 Token。独立 HTML 在自身样式中定义变量；项目已有主题文件时沿用其命名与来源。页面和自建组件按语义引用颜色，不在各处散写色值。实际样式是数值来源，最终 Markdown 记录落地结果。

## 制作 HTML 原型

沿用已有位置；默认交付 `docs/design/design-board.html`。页面、CSS、轻量脚本与说明放在这一个 HTML 中，首次打开先看到产品界面。必要外部库、字体与素材明确引用并说明联网依赖，无需初始化完整应用工程。

| 要素 | 应呈现的内容 |
| --- | --- |
| 字体与字重 | 实际加载指定资源，呈现中文、英文、数字及标题/正文/辅助文字的字号、字重、行高和字间距；缺少字体或字重时说明回退，不能只声明名称就声称已加载。 |
| 背景与配色 | 页面、导航、内容区、卡片和浮层的背景层次，以及文字、边框、强调色、状态色与焦点色。 |
| 组件与布局 | 指定组件和变体在真实页面中的尺寸、圆角、边框、阴影、图标及悬停、焦点、选中、禁用外观；保留参考中的布局比例和信息密度。 |
| 状态与动效 | 按需要用样例展示加载、空数据、错误和成功；动效可触发、可重看，体现触发方式、时长、延迟和缓动，并支持减少动态效果。 |
| 交互 | 用本地样例演示切页、标签、分页与浮层开合，弹窗和菜单可关闭且有合理焦点反馈，能看懂页面层级和底层关系。 |

不需要正式路由、登录鉴权、持久化或后端；模拟行为与真实接口状态分清，不歪曲已确认业务规则。组件无法直接用于 HTML 时可做视觉模拟，但必须标明差异，不冒称原库组件。

在 HTML 折叠的“组件与来源”区列实际使用的组件/库、用途、已知版本或变体、链接及必要定制；图标、字体、动效、参考、模拟数据与资源限制同处说明。区分直接使用、视觉模拟与候选资源，不编造版本或授权，不让说明挤占产品界面。指定组件的操作按相应 Skill，复用现有配置。

## 从成品整理 Token 文档

HTML 完成后直接整理 `docs/design/design-token.md`，记录名称、变量引用与实际值、用途和对应位置：颜色；字体与回退、字号、字重、行高、字间距；导航/内容尺寸、分栏、间距、控件、列表、表格、圆角、边框、阴影、浮层层级；动效触发、时长、延迟、缓动与减少动态效果处理。

从本版 CSS、主题变量和组件配置提取，复用现有命名，不从截图猜值或另造一套规范。根据反馈改原型时先更新样式，再同步 Token 文档。

## 直接交付

完整设计最终只交付一个 HTML 原型和一份 Token 文档，简述打开方式；仅草图按前述范围交付。交接注明草图或完整原型及真实位置，供 Spec、Issue 和实施引用。做好即交付，不等用户批准，不默认追加质量检测、截图审查、自动化测试、评分、自评循环或报告。另行要求评审或正式开发时，再按该任务处理。
