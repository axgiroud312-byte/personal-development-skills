# Issue 编写模板

写到没读过聊天的人也能接手。按任务大小删减或合并，现有平台模板可直接映射；只填真实依据、链接与状态。预期结果用于指导开发，执行节奏沿用 `to-tickets`，不用逐项复制测试与构建流程。

---

任务类型决定产出：调查交证据与结论；设计交 HTML 原型及随后提取的 Token；环境准备交必要配置和启动方式；功能/修复交约定行为及代码。没有必要就不增加额外工程或报告。

**小任务示例：允许分页选择 100 条。** 本次想实现：在现有 20、50 中增加 100。想要：省略参数仍默认 50，20、50 仍可用，无效值沿用原错误处理。不要：改变默认值、返回类型或其它分页逻辑。实际条数取决于匹配数据；引用现有接口，必要核对交由所属目标收尾。
