# 好设计与坏设计

读取 [好坏设计参考](references/design-quality.md)，按当前内容、用户参考和任务范围运用其中指导。原指导正文保持不变，不复制到其他技能。

需要具体制作参数时再读取 [设计系统与组件规则](references/design-system.md)，已有主题、组件与用户约定优先，不为套规则扩大改动。

本技能提供指导，具体产物由当前任务决定。用户主动调用 `design-ui` 后才进入独立设计版流程；其中提到的 Token 文档在用户确认设计版后整理。普通 UI 实现可直接使用这些指导，不因此启动设计版、正式规格、任务拆分或循环优化。
