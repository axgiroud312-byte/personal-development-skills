# 003：查看并编辑同一订阅，返回原列表位置

状态：待实施；本次只建立任务。

## 本次要做什么

- **本次想实现什么：** 从列表进入条目详情、修改现有订阅并保存，返回列表后看到相同条目的最新内容。
- **想要什么：** 稳定 ID 贯穿详情、编辑和存储；取消不写入，保存后刷新仍保留；返回列表恢复原页码。
- **不想要什么：** 不另建字段或错误定义，不把更新实现成新建，不增加归档和删除。归档未决规则见 [Spec 后续范围](../specs/subscription-management.md#未决项与后续范围)。
- **依据：** [业务对象与规则](../specs/subscription-management.md#业务对象与规则)、[API 与分页](../specs/subscription-management.md#api-与分页)、[错误约定](../specs/subscription-management.md#错误约定)、[界面职责](../specs/subscription-management.md#界面与待制作设计)。

## 局部方案

在 002 的共同服务与存储上补齐按 ID 查询和完整更新，接通列表详情入口、详情读取、编辑状态和返回导航。复用新增表单的字段处理与错误显示；仅对同一 ID 的原记录进行更新，列表顺序不变。

详情通过 API 读取，不能只依赖列表缓存；保存后重新读取详情，返回列表时重新读取原页码。不存在记录、保存失败和保存成功后重读失败均按 Spec 对应分支处理，取消编辑只退出本地编辑状态。

## 关联与依赖

- [002](002-list-create.md) 的服务、真实存储和共用表单基础是前置；在其上扩展，避免与其并行重写共享代码。
- [001](001-desktop-design.md) 的详情/编辑与导航设计用于界面定稿；公共合同已由 Spec 给定，不等待额外业务确认。

## 预期结果

负责 [Spec 完成标准](../specs/subscription-management.md#完成标准) **C8–C10**，并覆盖 **C3、C5–C7、C11、C12 的编辑分支**：从非第一页进入再返回仍能定位；修改持久化且 ID 不变；取消不写入；不存在、校验失败或存储失败不会产生伪成功。

与 002 合并后由整体负责人收尾核对完整目标和必要验证；本任务不预填实际进度或检查结果。
