# Issue 005：实现真实订阅列表与分页

- 状态：待开始
- 优先级：P1
- 依赖：[003](003-subscription-api.md)、[004](004-desktop-shell-and-settings.md)
- 关联：[技术方案第 5、7、9 节](../technical-plan.md)

## 问题与目标

让使用者从真实存储看到订阅名称、金额和下次续订日期，并能分页浏览和打开详情。列表是新增、编辑后读取结果的共同入口。

## 工作范围

1. 从本地 API 获取分页数据，以服务返回的 `total` 驱动分页。
2. 按契约显示币种和金额，按本地日历日期显示 `renewal_date`；不自动推算下一周期。
3. 处理加载、空列表、读取失败、有效页切换和越界页回退；请求失败不能伪装为空列表。
4. 提供新增入口和详情导航，传递当前页码。
5. 提供可复用的重新读取动作：新增后读取第一页；编辑返回时读取来源页；不依赖缓存对象伪造最新结果。

## 验收条件

- [ ] 使用真实 API 数据，名称、币种、分位金额和日期显示符合契约。
- [ ] 超过一页时无重复或遗漏，总数和页码正确，重复读取顺序稳定。
- [ ] 总数为零时显示空态；API 或文件失败时显示可重试错误。
- [ ] 从第二页或后续页打开详情，可保留来源页码。
- [ ] 新增后的第一页读取和编辑后的来源页读取均可由调用方触发并获取真实结果。

## 不包括

搜索、筛选、用户自选排序、报表、金额汇总、汇率换算和归档列表。
