# Issue 007：实现详情、编辑与返回列表

- 状态：待开始

## 问题与目标

让使用者查看单条订阅并编辑现有字段，保存后在详情和列表中看到同一份更新数据，且可返回原来的列表页。

## 工作范围

1. 根据路由 ID 独立读取详情，支持直接进入、刷新、加载失败与记录不存在状态。
2. 在详情提供四个业务字段的编辑能力；ID 只读；复用新增的金额、日期和错误语义。
3. 提交可编辑字段；服务端按完整记录校验后保存；保存成功重新读取详情，失败保留用户输入。
4. 返回列表时恢复来源页码并重新读取；直接进入详情时回到第一页；来源页失效时按分页契约回退。
5. 区分写入成功后重读失败与写入本身失败，避免用户误判已保存数据。

## 验收条件

- [ ] 从列表进入和直接打开详情都读取同一真实记录，刷新后仍可使用。
- [ ] 修改名称、金额、币种、日期能持久化；刷新及服务重启后仍为新值。
- [ ] 记录 ID、列表位置和其他记录保持不变。
- [ ] 从第二页进入详情后返回仍为第二页，且显示重新读取的更新内容。
- [ ] 不存在记录、非法字段和存储故障有明确错误；失败不丢输入。
- [ ] 详情和表单没有归档状态或关于归档后可否编辑的隐含规则。

## 不包括

删除、归档、编辑历史、撤销、自动推进续订日期或订阅周期管理。
