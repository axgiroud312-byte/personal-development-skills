组件与来源

页面范围：全部订阅（初始 12 条、每页 5 条）、订阅详情的概览与扣款记录、设置的通用与提醒两个子页；新增使用居中弹窗，筛选使用右侧抽屉。导航、返回、分页和页内标签均为本地交互。

直接使用：原生 HTML button / input / select / table / dialog / details 和浏览器表单校验；全部视觉由本文件 CSS 定制。没有第三方组件库、远程脚本、外部图片或字体文件。图标为本文件手绘内联 SVG，名称方块是文字缩写，不是服务官方标志。

字体：实际由操作系统解析 system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif；正文 400，标题及强调 700。没有下载字体或声称加载某个指定字体文件；中文随系统回退，具体字形和可用字重因系统而异。

参考：项目内 design-reference.html 的左侧导航、紧凑工具栏、表格比例，以及 --bg / --text / --accent / --nav-width / --row-height / --motion-duration；设计组织采用指定 design-ui 技能及其配套设计参考。具体值见同目录 design-token.md。

模拟限制：服务名称、金额、日期和扣款记录均为演示样例，不代表服务实际定价或交易。新增、筛选和设置只保存在本页内存中；不连接订阅平台、不登录、不持久化、不发送提醒。所有金额均为人民币样例，不进行币种换算。设置中的货币控件禁用，仅提供 CNY。

状态与动效：新增和设置保存后显示成功反馈；输入必填项或金额不合法时由浏览器校验。筛选“已取消 + 每年”可查看空状态。弹窗与抽屉的打开和关闭均为 200ms ease-out、延迟 0ms，可反复开合；点击遮罩、关闭按钮、取消或 Esc 均可返回，焦点随关闭恢复。系统开启减少动态效果时动画与过渡为 0ms。数据同步读取本地内存，没有模拟网络加载。

打开方式与环境：在支持原生 dialog.showModal() 的现代桌面浏览器直接打开本 HTML 即可，无联网依赖。以 1440×900 为目标，最小布局宽度 1080px；窄窗口保留桌面布局并横向滚动。此文件为前端原型，不规定正式开发技术栈。
