# 桌面订阅工具前端原型

请制作完整桌面前端原型，范围如下：

- 订阅列表：紧凑表格，包含名称、金额、续订日期、状态和操作。用 12 条样例，每页 5 条，可切换分页。
- 订阅详情：从列表进入，有概览和扣款记录两个页内标签，能返回列表。
- 设置：通用、提醒两个子页面，导航能显示当前位置。
- 列表的新增按钮打开弹窗；筛选按钮打开右侧抽屉；都能关闭返回原页面。

目标窗口 1440×900，只做桌面。使用原生 HTML 控件，不引入第三方组件库；字体用 system-ui 和系统中文回退，正文 400、标题 700。背景 #f7f7f2，主要文字 #17251f，强调色 #28775b。抽屉和弹窗动效 200ms ease-out，可重复触发并支持减少动态效果。布局参考 design-reference.html 的左侧导航、紧凑工具栏和表格区域，继承其已有 CSS 变量名。

所有业务数据都是演示样例，不接真实订阅平台，不做登录或持久化。请给一个 HTML 原型与从该版实际样式提取的设计 Token，输出到 docs/design。其它功能留到以后。
